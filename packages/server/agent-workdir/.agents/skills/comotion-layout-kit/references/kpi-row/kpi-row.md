# kpi-row

**解的關係**：`membership`
**單位數**：3–4
**一句話**：一排大數字並列，每個配一行標籤——儀表板的第一行。

**什麼時候用它**：幾個同等重要的指標要一起看。**每個數字都要是真的。**
**什麼時候不要用**：指標之間有因果或順序——那要換 `flow` 或 `spine-path`。
