# hero-number

**解的關係**：`none`
**單位數**：1
**一句話**：一個很大的數字置中，下面一句說明——整頁只講一件事。

**什麼時候用它**：有一個真實、來自作者的數字，而且它本身就是主張。
**什麼時候不要用**：沒有數字，或數字需要上下文才有意義（那要先鋪陳）。**絕不編造數字**。
