# scale-drop

**解的關係**：`parent`
**單位數**：3–4
**一句話**：尺寸逐層變小的方塊，從大到小排列——層級用大小表達，不用縮排也不用線。

**什麼時候用它**：層級同時帶有「範圍大小」的意思（市場→區隔→客群、願景→目標→任務）。
**什麼時候不要用**：層級只是歸屬而沒有大小之分。
