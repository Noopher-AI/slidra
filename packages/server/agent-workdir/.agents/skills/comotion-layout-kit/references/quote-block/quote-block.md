# quote-block

**解的關係**：`none`
**單位數**：1
**一句話**：一段引用佔據版面，出處在下方——把別人的話當成這一頁的全部。

**什麼時候用它**：客戶的原話、使用者回饋、權威的判斷。**引用必須是真實的**。
**什麼時候不要用**：自己的主張。把自己的話排成引用會顯得矯情。
