# media-stage

**解的關係**：`none`
**單位數**：1
**一句話**：一段影片（或音訊）佔據舞台中央，上方一句話說明要看什麼——播放前後都成立的頁面。

**什麼時候用它**：有一段真實的影片／音訊要播。示範、訪談、實錄、產品畫面。
**什麼時候不要用**：素材還不存在。**不要放佔位的黑框**——沒有影片就換一個版面，等素材到了再改回來。

## 線框

```xm完整 SVG：見同資料夾 `media-stage.svg`。槽位

| 槽位 | 角色 | 內容 | 字數預算 | 行數 |
|---|---|---|---|---|
| 標題 | `label` | **說明要看什麼**，不是影片檔名 | 18 字 | 1 |
| 影片 | `node`（`video` 元素） | 16:9 置中 | — | — |
| 出處與長度 | `label`（`caption`） | 「訪談片段・1 分 20 秒」 | 20 字 | 1 |

## 節奏

影片框維持 **16:9**（畫布是 1280×720 時，800×450 置中是安全的尺寸——上方留給標題、下方留給出處）。不要讓影片滿版：滿版之後標題無處可放，而且播放控制項會壓到內容。

標題的字要能**在影片播完之後仍然成立**——聽眾看完會回到標題確認自己該記得什麼。

`blueprint.shape` 寫 `media-stage`。

**動畫**：只有一步（標題與影片一起進場）。**影片元素本身不加進場效果**——它會跟播放行為打架。

## 怎麼放進去

```
co-motion asset import <id> <影片路徑或 URL>
co-motion element insert video <id> slides/00N.svg --x 240 --y 170 --width 800 --height 450 --media assets/<檔名>
```

外部平台的影片用 `--embed <provider>` 加 `--href`，不要下載再匯入。

## 變體

- **左影右文**：影片縮到 640×360 放左側，右側放三個觀看重點——適合「邊看邊講」。
- **播放後的頁**：同樣的版面但影片換成一張截圖，上面疊結論——影片播完後的下一頁。
- **音訊**：`element insert audio`，框改成一條窄的波形帶（高度 120），其餘相同。
