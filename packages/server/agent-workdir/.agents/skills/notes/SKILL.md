# 補簡報者備忘稿

使用者說「幫每頁補備忘稿」或「這頁的講稿寫一下」時的完整流程。備忘稿是口語、可以直接念出來的講稿，不是投影片文字的重抄。
命令的完整參數見 `reference/commands.md`，這裡只寫順序與容易做錯的地方。

## 觸發語

「補備忘稿」「寫講稿」「簡報者備忘」「全場 N 分鐘」「這頁大概要講多久」。

## 輸入格式

- 目標：某一頁或全部頁。
- 選填：總時長（例如「全場 10 分鐘」）或單頁時長。

## 步驟

1. **沒指定目標時不要猜**：先 `co-motion ls <presentation-id> slides` 看現況，問使用者是哪一頁或全部，**不執行任何寫入命令**。
2. **指定的頁不存在**：明確回報「這份簡報只有 N 頁」，不執行。
3. **讀取內容**：逐頁 `co-motion cat <presentation-id> slides/00N.svg`，讀出標題與要點。
4. **該頁已有備忘稿**：**先看現有內容**（`cat` 輸出裡的 `<comot:notes>`），問使用者是要覆蓋還是保留——`slide notes set` 是整份覆寫，沒有 append，**不得未經確認直接覆蓋**。
5. **寫入備忘稿**：`co-motion slide notes set <presentation-id> slides/00N.svg '<口語化講稿>'`。一頁一個命令，做完一頁確認一頁再做下一頁。
6. **指定總時長**：用「總秒數 ÷ 頁數」估每頁秒數，講稿長度依中文口語約每分鐘 240 字換算，並在回報裡列出每頁的預估秒數。
7. **指定單頁時長**：同上換算方式，只針對該頁。
8. **要求清空**：`co-motion slide notes set <presentation-id> slides/00N.svg ''`（空字串合法，會清空該頁備忘稿）。

## 使用的命令

`co-motion ls`、`co-motion cat`、`co-motion slide notes set`。

## 回報格式

逐頁列出：頁面路徑、備忘稿內容（或摘要）、若有指定時長則附上估算秒數。若某頁因既有備忘稿而暫停，說明目前內容並等待使用者確認。

## 不可做的事

- 不在未確認的情況下覆蓋既有備忘稿。
- 不把投影片上的文字原文重抄一遍當備忘稿——內容必須是口語、第一人稱、可直接念出來。
- 講稿內容不得含單引號（例如英文所有格）；改寫措辭避開，不要試圖用反斜線跳脫——反斜線一律會被拒絕。
- 不使用雙引號；引號一律用單引號。
- 不使用管線或重導向驗證結果——一律用 `cat` 讀回。
- 不寫任何檔案。
