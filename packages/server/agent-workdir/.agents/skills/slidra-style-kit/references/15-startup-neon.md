# 15 · startup-neon

**第一秒的感覺**：近黑底配洋紅與紫的漸層光。像一場晚上七點的產品發表會——亮、快、有點吵，但你會記得。

**適合**：產品發表、募資簡報、招募、任何要製造記憶點的場合。
**不適合**：內部檢討、風險說明。這個風格自帶樂觀，不適合講壞消息。

**為什麼是這個配色**：洋紅與紫是相鄰色，所以放在一起是「發光」而不是「衝突」；底色留一點藍讓光有地方可以擴散；文字用純白，這個亮度需要最強的對比。
