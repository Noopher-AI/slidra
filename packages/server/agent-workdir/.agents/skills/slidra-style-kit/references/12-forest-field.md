# 12 · forest-field

**第一秒的感覺**：深苔綠配麥稈色。像走進一片被整理過的林地——有生命、有秩序，不是野生也不是人工。

**適合**：農業、食品產地、ESG、戶外品牌、地方創生。
**不適合**：都會科技、金融。綠色在這些主題裡會被讀成「環保口號」而不是主體。

**為什麼是這個配色**：主色是深苔綠（不是草綠——草綠太亮太塑膠）；accent 用麥稈黃，兩者是同一片土地上會同時出現的顏色，所以並置不吵；背景用極淺的米綠，白底會讓綠色浮起來像貼紙。
