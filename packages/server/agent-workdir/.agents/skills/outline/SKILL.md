# 大綱轉投影片

把作者貼給你的大綱或文章，長成一份完整的簡報：每個小節一頁，標題頁一頁，字級與版面沿用簡報既有的範本，不自己發明一套。

## 觸發語

作者的訊息以 `/comotion-outline` 或 `/outline` 開頭，後面接的文字就是這個 skill 的輸入。

## 輸入格式

斜線後面應該是一份大綱或一篇文章：可以是條列式小節，也可以是完整段落的文章（由你自己抓出小節結構）。每個小節通常會長成一頁，小節底下的重點會長成那一頁的要點清單。

## 步驟

1. **先看現有的頁面**：`co-motion ls <presentation-id> slides`，再 `co-motion cat <presentation-id> slides/00N.svg` 讀一兩頁，確認標題頁與內容頁各自的元素、字級、座標——新產出的每一頁都要照抄這組數字，不要自己發明版面。
2. **抓出大綱的結構**：一個主標題（或第一層小節）當標題頁，其餘每個小節各自一頁。一個小節一行也沒關係，就產一頁，不要為了湊頁數硬拆。
3. **逐頁產生，一頁做完再做下一頁**：
   - 有可抄的範本頁時，`co-motion slide duplicate <presentation-id> slides/00N.svg` 複製後用 `co-motion text set` 覆寫標題與要點文字；沒有範本可抄時才用 `co-motion slide add`（`--template templates/00N.svg` 用 `template list` 查到的路徑，或省略走空白頁）。
   - 空白頁沒有既有元素，改用 `co-motion textbox add` 建立標題與要點文字框，`--x`／`--y` 抄鄰近頁面同類元素的座標。
   - 每一頁都用 `co-motion slide notes set` 寫一段非空的備忘稿，摘要這一頁在講什麼。
4. **驗收**：每一頁都 `co-motion cat` 讀回，確認標題與要點文字、備忘稿都寫進去了。
5. **回報**：照下面的固定格式，逐頁列出。

## 使用的命令

`ls`、`cat`、`template list`、`slide duplicate`、`slide add`、`text set`、`textbox add`、`slide notes set`。

## 回報格式

逐頁一行：`第 N 頁（slides/00N.svg）：<標題>——新增 / 覆寫`。全部做完後加一句總結（共幾頁）。

## 不可做的事

- **輸入完全不存在或只有空白**：不要猜、不要生成任何一頁，回一句話問作者要用哪份大綱。
- **輸入是一句閒聊而不是大綱**：不要硬把它編成投影片內容，回話說明這看起來不是大綱，請作者確認。
- **不要自己發明字級、顏色或版面**：一律沿用第一步驟讀到的既有範本；封面與內容頁字級不同是預期行為，不要把封面「修得跟內容頁一樣」。
- **不要對 `comment add` 或任何留言命令下手**：`/outline` 只新增投影片內容，不留言、不改既有留言。
- **大綱文字含有半形單引號 `'` 時**：不要靜默丟棄或改寫，在對話裡告訴作者這段打不進命令列，請他換一種寫法。
