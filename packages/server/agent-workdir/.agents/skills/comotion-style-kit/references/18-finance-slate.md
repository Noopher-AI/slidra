# 18 · finance-slate

**第一秒的感覺**：石板灰的底、香檳金的重點。像一份私人銀行的年度報告——安靜、昂貴、不需要大聲。

**適合**：財報、投資、法人說明、高資產客戶。
**不適合**：新創與早期產品。這個風格暗示「我們已經很久了」。

**為什麼是這個配色**：灰是唯一的主體，金只出現在數字與一條細線上。**金的面積超過 5% 就會變成廉價**——這個配色的貴氣來自克制而不是金色本身。

**字型與對比**：標題襯線、數字用 Inter（它的表格數字對齊得最好）。密度 `balanced`，財務頁面本來就有較多欄位。

**間距節奏**：級距標準。這個風格靠嚴格的欄位對齊。

**建議背景**：01 `soft-blobs`（opacity 0.3，幾乎看不見的層次）。
