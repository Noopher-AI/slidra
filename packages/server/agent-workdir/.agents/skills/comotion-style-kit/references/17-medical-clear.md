# 17 · medical-clear

**第一秒的感覺**：純白、鋼藍、一點薄荷。像一間乾淨的診間——沒有多餘的東西，每個標示都看得懂。

**適合**：醫療、健康、臨床資料、公共衛生、任何錯誤代價很高的場合。
**不適合**：品牌與情感訴求。它刻意沒有個性。

**為什麼是這個配色**：藍與綠是醫療場域的既有語彙（藍＝儀器、綠＝手術），沿用而不是發明；紅只留給警示，**不可以拿來當裝飾**；背景純白，因為這個領域的圖表需要最中性的底。
