# 11 · sunset-gradient

**第一秒的感覺**：珊瑚紅到琥珀黃的暖色群，底是很淺的杏色。像傍晚的光——熱、有動勢、讓人想往前。

**適合**：消費性產品、發表會、募資、面向年輕族群。
**不適合**：需要冷靜判斷的內容（風險、法遵、財務細節）。暖色會讓判斷失準。

**為什麼是這個配色**：三個暖色排成一個色階（珊瑚→橘→琥珀），所以它們並列時看起來是「同一件事的三個階段」而不是三個無關的顏色。唯一的冷色是深藍灰的文字色，用來把畫面拉回地面。
