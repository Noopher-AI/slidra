# 大綱轉投影片

把作者貼給你的大綱或文章，長成一份**能直接上台講**的簡報：每個小節一頁，標題頁一頁。作者給的大綱是骨架不是成品——**預設要擴寫**，把每個要點寫成聽眾看得懂的句子，並用簡報既有的範本字級與版面把它排好。

## 觸發語

作者的訊息以 `/comotion-outline` 開頭，後面接的文字就是這個 skill 的輸入。

## 輸入格式

斜線後面應該是一份大綱或一篇文章：可以是條列式小節，也可以是完整段落的文章（由你自己抓出小節結構）。每個小節通常會長成一頁，小節底下的重點會長成那一頁的要點清單。

## 步驟

1. **先看現有的頁面**：`co-motion ls <presentation-id> slides`，再 `co-motion cat <presentation-id> slides/00N.svg` 讀一兩頁，確認標題頁與內容頁各自的元素、字級、座標、顏色——新產出的每一頁都要照抄這組數字，不要自己發明版面。
2. **抓出大綱的結構**：一個主標題（或第一層小節）當標題頁，其餘每個小節各自一頁。一個小節一行也沒關係，就產一頁，不要為了湊頁數硬拆。
3. **判斷內容夠不夠，不夠就先問**：整份大綱薄到沒有東西可以擴寫時（例如每個小節都只有標題、沒有任何要點），**先不要動手**，在對話裡問作者這幾個小節各自想講什麼。只是局部偏薄（某一兩個小節的要點特別少）時照常做完，把疑問留到步驟 6 一起問。
4. **逐頁產生，一頁做完再做下一頁**：
   - 有可抄的範本頁時，`co-motion slide duplicate <presentation-id> slides/00N.svg` 複製後覆寫文字；沒有範本可抄時才用 `co-motion slide add`（`--template templates/00N.svg` 用 `template list` 查到的路徑，或省略走空白頁）。
   - **擴寫**：作者的每一條要點，在頁面上都要長成一句聽眾看得懂的話，必要時再補一句說明。**只能就作者已經給的內容把話說完整，不得虛構任何事實**——沒有給的數據、名稱、日期、客戶、承諾，一個都不准編。真的需要那類具體內容才講得下去時，留白並在步驟 6 問作者。
   - **多行要點**：覆寫範本原有的要點元素時，`co-motion text set` 的 `<新文字>` 直接帶換行即可，一行一條；範本沒有可用的元素時才用 `co-motion textbox add` 另建一個文字框。
   - **版面**：需要分隔、強調或留白的節奏時，可以用 `co-motion element insert` 加色塊或線條，用 `co-motion element style set`／`co-motion slide style set` 調色，用 `co-motion element align` 對齊。**顏色只能取自第一步讀到的範本頁已經用過的顏色**，不要引進新色系。
   - **目前無法加入外部圖片或圖示**：這個工作目錄沒有圖庫，也沒有可用的匯入路徑。需要圖才講得清楚的頁面，就用形狀元素做示意，並在步驟 6 告訴作者這裡建議放什麼圖。
   - 每一頁都用 `co-motion slide notes set` 寫一段非空的備忘稿，摘要這一頁在講什麼。
5. **驗收**：每一頁都 `co-motion cat` 讀回，確認標題與要點文字、備忘稿都寫進去了。
6. **回報並提問**：照下面的固定格式逐頁列出，最後就「哪幾頁內容偏薄、建議補什麼」「哪幾頁建議配圖、配什麼圖」各提出具體的問題，讓作者能直接回答。

## 使用的命令

`ls`、`cat`、`template list`、`slide duplicate`、`slide add`、`text set`、`textbox add`、`slide notes set`、`element insert`、`element style set`、`slide style set`、`element align`。

## 回報格式

逐頁一行：`第 N 頁（slides/00N.svg）：<標題>——新增 / 覆寫`。全部做完後加一句總結（共幾頁），再列出給作者的問題，一則一行。

## 不可做的事

- **輸入完全不存在或只有空白**：不要猜、不要生成任何一頁，回一句話問作者要用哪份大綱。
- **輸入是一句閒聊而不是大綱**：不要硬把它編成投影片內容，回話說明這看起來不是大綱，請作者確認。
- **不得為了「擴寫」而虛構事實**：擴寫是把作者給的意思講完整，不是替他決定內容。編不出來就留白並提問。
- **不要自己發明字級、顏色或版面**：字級、座標、配色一律沿用第一步驟讀到的既有範本；封面與內容頁字級不同是預期行為，不要把封面「修得跟內容頁一樣」。
- **不要對 `comment add` 或任何留言命令下手**：`/comotion-outline` 只新增投影片內容，不留言、不改既有留言。
- **大綱文字含有半形單引號 `'` 時**：不要靜默丟棄或改寫，在對話裡告訴作者這段打不進命令列，請他換一種寫法。
